# Awesome Free Tools

Catálogo de ferramentas gratuitas para otimização de tempo, produtividade e redução de custos em cooperativas de crédito e unidades administrativas.

## Acessar o catálogo

https://otimizacaodiaria.vercel.app/

## Objetivos

- Reduzir despesas com assinaturas de ferramentas externas.
- Melhorar a produtividade administrativa.
- Automatizar tarefas repetitivas.
- Apoiar a elaboração de documentos, planilhas e relatórios.
- Facilitar a modelagem de processos e a gestão de projetos.
- Disponibilizar alternativas gratuitas para ferramentas com acesso restrito.

## Organização

**Filtro Todas:** ferramentas agrupadas por categoria, na ordem de prioridade administrativa.

**Categoria selecionada:** ferramentas daquela categoria em ordem alfabética.

Cada ferramenta permanece vinculada à sua categoria, sem misturar diferentes finalidades.

## Acesso e alternativas

O catálogo verifica respostas HTTP dos links a partir da rede utilizada na execução do script.

| Status | Significado |
| --- | --- |
| HTTP_OK | O servidor respondeu com sucesso ao teste |
| HTTP_403 | O servidor ou algum controle de acesso recusou a requisição |
| HTTP_404 | A página solicitada não foi encontrada |
| HTTP_429 | O servidor limitou as requisições |
| REDE_INDISPONIVEL | Não foi possível concluir o teste de rede |
| NAO_VERIFICADO | Não há confirmação de disponibilidade |

**Importante:** um erro HTTP 403 não comprova, isoladamente, bloqueio pelo FortiGuard. Da mesma forma, HTTP 200 não comprova liberação pelo firewall corporativo. O resultado pode variar conforme a rede, autenticação, navegador e políticas institucionais.

Ferramentas com acesso não confirmado continuam com seus hiperlinks disponíveis. Quando possível, é exibida uma alternativa gratuita da mesma categoria que respondeu HTTP_OK no teste.

## Imagens de prévia

As imagens devem representar interfaces reais das ferramentas.

- Preservar capturas reais já cadastradas.
- Pesquisar imagens reais no Google Imagens.
- Não inventar capturas ou utilizar imagens de produtos diferentes.
- Não acessar automaticamente sites bloqueados para obter screenshots.
- Manter os links das ferramentas disponíveis mesmo sem preview.

O arquivo `pesquisas-google-imagens.csv` contém pesquisas específicas para encontrar imagens reais das ferramentas.

As imagens selecionadas podem ser salvas na pasta `google-imagens-importar` com o nome indicado no CSV, para importação na próxima execução.

## Relatório de disponibilidade

O arquivo `verificacao-links.csv` registra os resultados dos testes HTTP.

Os resultados representam a rede e o momento em que foram executados, não uma homologação definitiva.

## Segurança

O catálogo não representa autorização institucional para uso de serviços externos.

Não inserir dados pessoais de cooperados, documentos bancários ou informações confidenciais em ferramentas externas sem autorização da cooperativa.

Não tentar contornar bloqueios de firewall, proxy ou outras políticas de segurança.

## Alternativas gratuitas em cards independentes

Cada alternativa gratuita e cadastrada como ferramenta independente no `tools.json`, com:

- Nome proprio.
- Descricao da funcionalidade.
- Categoria correspondente.
- URL de acesso.
- Imagem de preview quando disponivel.
- Card completo no catalogo.
- Identificacao da ferramenta que pode substituir.

As alternativas nao sao apresentadas como simples hiperlinks dentro de outros cards.

A disponibilidade no firewall corporativo depende das politicas de rede. Respostas HTTP nao garantem liberacao institucional.
