# Awesome Free Tools

Catálogo gratuito de ferramentas para cooperativas de crédito e unidades administrativas.

## Acessar

https://otimizacaodiaria.vercel.app/

## Objetivo

Reduzir custos com assinaturas, otimizar tempo e melhorar a produtividade administrativa.

## Funcionamento

- **Todas:** ferramentas separadas por categoria, em ordem de prioridade administrativa.
- **Categoria selecionada:** ferramentas daquela categoria em ordem alfabética.
- **Links:** toda ferramenta com URL válida mantém acesso, mesmo sem imagem.
- **Previews:** utilizar capturas reais da interface, sem imagens inventadas.
- **Firewall:** respeitar bloqueios institucionais e priorizar alternativas gratuitas, preferencialmente locais.

## Segurança

A presença de uma ferramenta no catálogo não representa autorização para utilização de dados internos da cooperativa. Respeitar políticas de segurança, privacidade e restrições de rede.

## Estrutura

- `tools.json`: ferramentas, categorias e links.
- `assets/app.js`: interface, filtros e navegação.
- `assets/site.css`: estilos.
- `assets/previews/`: imagens de prévia.
- `index.html`: página principal.
